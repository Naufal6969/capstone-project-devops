# CAPSTONE PROJECT DEVOPS

## Project Description
This project is a microservices-based application designed to demonstrate DevOps best practices, including Agile planning, Continuous Integration (CI), and Continuous Delivery (CD). It focuses on the Customer Accounts microservice.

## Build Status
![Build Status](https://github.com/Gemendun/capstone-project-devops/.github/workflows/ci-build.yaml/badge.svg)

## Project Features
* **Microservices Architecture:** Independently deployable services.
* **CI/CD Pipeline:** Automated testing and deployment using GitHub Actions.
* **Agile Planning:** Managed via GitHub Projects and Kanban boards.
* **Containerization:** Deployed using Docker and managed with Kubernetes.
